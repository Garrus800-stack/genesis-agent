## [7.9.37]

The version that makes autonomy trustworthy end to end — one entry, because what matters is what ships, not how many passes it took.

The goal engine itself was straightened first: `abandoned` counts as terminal everywhere (dedup fences included), a fresh goal no longer skips its first step (plan-world resume reads a transient checkpoint instead of mutating the goal), an activity's curated preset steps actually reach the loop, failure messages carry their attempt count, and every step failure prints a visible diagnosis line with cause and action.

Model truth first: context windows are now resolved from the backend itself (`/api/show`) instead of a hard-coded guess, `num_predict` is always explicit, cloud models get a fair first-chunk timeout with a two-strike memory that routes around genuinely dead streams, and `scripts/probe-model.js` measures any model's real behaviour before it is trusted.

The chat router grew a project-wide, case-insensitive file resolver: a bare filename finds its file in one turn, every successful read carries a provenance head (`\u{1F4C4} <file> ...`) — including reads through the `file-read` tool — pending file questions are remembered so an answer like "the one in docs/" resolves instead of re-asking, non-idle goals report their outcomes back into the chat, the same clarification is never asked twice in identical words, and a model that only announces tool use is re-prompted twice (the detector knows announce idioms and slash-commands-written-as-prose) before the user sees one honest status line instead of a stutter. Slash lines written next to real tool calls are confronted on the very next round ("these were NOT executed — send real tool_calls or drop them"), the system rule forbids the pattern without ever quoting an announce phrase the model could parrot, and a truncation continuation is invisible plumbing: it never greets, never asks the user which call was meant, and re-emits a cut tool_call block complete.

The agent's own inner voice finally has a memory: the mid-turn nudge and the post-tool synthesis used to rebuild a miniature world out of the last user message alone, so a reply as short as "ok" left the model blind — it could see the system prompt and nothing else, and a blind model can only announce what it would do. Both inner calls now carry the recent conversation, a question addressed to the human ("tell me what's next") is no longer mistaken for an announcement that needs prodding, and a nudge that produces no new tool call never nudges again — the announce cascade cannot form. The UI bundle is rebuilt on start whenever a source file is newer than it, so the running window can never again be an old build of itself.

A classified failure keeps its verdict all the way to the diagnosis (a deterministic parse error no longer prints as "unclassified"), and a structurally unreachable resource — a peer requirement in a habitat with no peers and discovery off — fails with a replan hint instead of parking the goal for hours. And service:llm now follows the model pool rather than the active-backend pointer, so an idle goal no longer blocks for a whole session when the preferred model is marked unavailable but a failover model is free.

Model choice is finally the user's: when the preferred model is unavailable, the configured fallback chain is consulted in the user's own order before any heuristic — an explicitly chosen alternative always beats a guess. The capability ranking was pinned to old generations (a brand-new model scored as "unknown" and lost to its own predecessor); it now scores families with a version bonus, so a newer model always outranks an older one of the same line and future releases are never treated as strangers. And the last-known-good snapshot — 400 files copied synchronously, measured at 4.8 seconds of a 6.7-second boot — now runs off the boot path: it still describes a boot that succeeded, but the window opens immediately.

The chat window finally tells the truth about work in progress — every tool shows a live running→done lifecycle inside the bubble, the typing pulse stays visible until the whole turn is finished, and when the turn closes, the final answer replaces all intermediate rounds: one clean bubble per turn.

Resilience has budgets and honest exits: a continuation that hits its cap fails explicitly and discards the partial instead of leaking fragments, the offending model is marked unavailable for thirty minutes and an exhausted chain degrades to the best local model; a model that writes past its continuation cap is named deterministically and never blindly retried, a module path is never mistaken for an npm package (no more install sub-goals for sandbox artifacts), the code prompt budgets its output to one compact script, and an empty model reply never reaches the user as silence — one honest line takes its place; foreign tool-call dialects (plural wrappers, empty hulls) are filtered before they reach the bubble, tiny stop-terminated continuations are accepted after two attempts instead of ten, a side-effect tool call (marking a moment, writing a journal line) no longer triggers a rewrite of an already-finished answer — the answer is the result, nothing is appended.

The dashboard's mood symbols are no longer stock emojis but Genesis' own marks — a translucent boundary layer whose contour stretches, tightens or shrinks with the state, one eye staying awake, drawn in the identity blue and gold and chosen by Genesis itself when shown the candidates (the three missing ring colors are filled in too); a missing stop signal is no longer read as a cut — a finished answer whose backend reported no done_reason was being declared truncated and rewritten a second time into the same bubble, so completeness is now decided from the text (a dropped stream still ends mid-word and is still caught), and every step diagnosis carries the real error text; the session cost cap enters a calm idle rest-mode instead of hammering, rate and budget failures park an activity for a few cycles, replans and repairs share a bounded budget with a hard step ceiling, and failed activity runs are persisted so the next session knows.

Generated code now reaches the parser clean: fenced blocks are stripped of leading prose before the acorn check, a file path is never parsed as code, verification failures classify as deterministic and trigger one regeneration with an explicit syntax warning in the prompt. The sandbox is grounded (`GENESIS_ROOT` and `NODE_PATH` on both spawn paths while the deliberate cwd isolation stays), the code prompt teaches absolute requires and declares self-inspection read-only, inline shell scripts with relative requires are rejected before approval with a teachable error, and the failure taxonomy can never resolve to null again — every failure has a name, and the goal archive carries the honest outcome. Investigate sub-goals are depth-limited to one (a decomposition child never spawns another investigate), `parentGoalId` survives a boot, obstacle logs never say "undefined", and a terminal child releases its blocked parent.

Autonomy levels mean what they say: the step-type alias table is one truth for planner and loop alike, so phantom "unknown step type" blockers are gone; when a plan genuinely needs approval the card names the goal, the reason, the real blockers, the consequences of Approve/Reject and the current trust level; full autonomy never asks for plan approval — except for self-modification, which is gated at every path and never trust-bypassed while the security setting demands confirmation; and an unanswered card parks the goal for retry instead of hanging into the global abort. Goal families persist across sessions into the planning prompt so fresh souls vary their first steps, crash boots leave a trace in the flight recorder, shells spawn ComSpec-safe on Windows, and the full contract suite for this version pins 77 behaviours.
