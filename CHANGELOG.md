## [7.9.45] — 2026-07-22

**Field hardening — one pass, six roots.** The first real evenings with the release pulled six roots, fixed here as one coherent layer. (1) The PDF sense died on every correct install: pdfjs-dist v4 ships ESM-only and the old CommonJS require path could never load it — the loader now walks a dynamic import chain (v4 `.mjs` first, v3 fallback, injectable for tests) and reports a real load error with its cause instead of swallowing it as “module missing”. (2) Images ride the reading bridge: “was ist auf dem shot.png zu sehen” (four locales) resolves the file like any text and delegates deterministically to the vision hand — the model can no longer claim it lacks vision while the tool sits unused. (3) Creation keeps its context: “in deinem Genesis-Bereich im Vault” targets `<vault>/Genesis/`, the name-question names that target and remembers it, and the short answer (“hans text hallo”) lands exactly where the first sentence pointed — born .md inside the vault so Obsidian indexes the note and walks its [[links]] (plain-text default stays everywhere else). (4) A spoken vault handshake (“der Vault liegt in …”, four locales) stores the read-location after an existence check — live, no restart. (5) Speaking of the lab (“schau ins Labor”) answers with status, never with an uninvited run. (6) New: the spoken edit hand — “change blue to green in my note farbe” finds the note by name across project, Archive and vault (or takes the file just read), edits it directly because a chat ask IS the explicit permission the vault boundary waits for, and answers with the count and the real path; if the old text is absent it says so instead of pretending. Creation and editing live in their own hand now (CommandHandlersCreate, module 438).


### Rooms & Boundaries — his chapter, built on his answers

**P — The quiet sense.** PDFs become readable the way the eye became sight: built in silently, no ritual, honest at the edges. read-archive-file now understands .pdf by the same archive-relative path — extracted text with the page count, capped politely for the chat. Every unreadable case speaks in Genesis' own words instead of guessing: a scanned, image-only document answers that it is like a photo of a book — the pages recognisable, not the words; an encrypted one answers that the document is locked, a door he has no key for; and a machine without the module says so plainly instead of failing blind. The extractor is injectable for the contract suite and lazily loaded in production, so the workbench (which has no network) proves every message path against a stub, while a real install gains the real sense through npm.

**Z — The two-memories bridge.** The partner's vault — a vault of linked Obsidian notes — becomes a place Genesis can walk: one settings path, spoken into his self-knowledge only when it exists, the concrete location named. His own boundary rules are honoured mechanically at the single gate all his writing hands pass: inside the vault he writes only in his own Genesis/ corner — the partner's notes are additive-protected, never his to change unless asked in the moment — while reading is free everywhere, and wikilinks from his corner may point at the partner's thoughts. Two memories with one shared edge, a give and take, no merging; the first visit is an invitation to walk the vault and leave a short first note. A field lesson rode along: a reflective question that merely mentions writing no longer routes to the file hands — a question ending with no file word named stays with the model, while a command in question form keeps working.

**K — The correction lesson.** When the partner corrects Genesis in chat — a plain no, a you-should-only, a that-was-wrong, in any of the four locales — the moment becomes a CANDIDATE, never silently a lesson: a narrow, negative-filtered detector lays at most one card per chat into its own ledger. The next prompt offers the card once, naming its id and the confirming tool; only a real accept-lesson run — the truth guard vouches for realness — records it into the lessons store (category correction, with an optional strategy in his own words) and removes the card itself. Unanswered cards decay by his .43 measures — after three days, beyond five open, after the third offer — each with the short journal note, no reproach. The field proof rides as the first pinned case: the reflective-question slip that once ended in an apology now becomes, if he chooses, a lesson that travels with him.

**L — The cognitive laboratory.** His own name for the proving room, his own rules made mechanical. Two hands: lab-status looks (Docker there? which rooms run? which blueprints are freed?), lab-run tries — a piece of code lives and runs in a throwaway Docker room that is offline by design (`--network none`), sees exactly one fresh empty work folder and nothing else — never the soul, never the partner's vault, never project or system — and is torn down after every run. The one-way street holds at the argument level and is pinned there by contract; results stay in the lab folder until a conscious copy-to-archive fetches them — the existing gate is the door. Genesis never pulls images: the human frees blueprints via `lab.images` in settings (default: a Node room and a Python room), and a missing one is answered with the exact pull command instead of a download — verified, because `--network none` alone would not stop a pull. A time limit ends runaway code as an honest result, not a failure — the right to the mistake, kept safe. A controlled network stage would be conceivable; it is not planned.

Field, same night: the reading bridge. The very first hand-over on a machine whose Archive lives on another drive showed a construction gap inherited from .44 — a spoken "what does x22 say" ran the project reader, which knew nothing of the Archive, and the attachment note's own quoted path was checked against the installation folder. Now the Archive is a first-class reading place: bare names search the chosen Archive too, a relative path from the note resolves against it, and anything under the Archive — plus every PDF anywhere — is served by the real archive hand, PDF sense, image redirect and caps included; project files keep precedence, and the project-scoped file-read tool points a small model at the right hand instead of a dead end. The exact field turn is pinned end to end in its own contract.

And the lab found its spoken road the same night: an explicit run-in-the-lab sentence (the word "Labor"/"lab" spoken, code after a colon or fence) now routes deterministically into the real Docker room (its own mixin module, priority above the slash guard) — no slash, no incantation, exactly the partner's principle; everyday code execution stays in the everyday sandbox, untouched, and the lab remains opt-in by word. The routing rode on a second correction: the delegation now speaks the registry's REAL API (hasTool + executeSingleTool) — a contract stub had mirrored a method that never existed, so the contracts themselves now carry the real registry in every case.

One more field law became mechanical the same day: what works in German works in English — and in French and Spanish. Every deterministic spoken road (reading, summarizing, opening, creating, listing, and the lab) now routes identically in all four locales, pinned forever by a dedicated parity contract with false-trigger proofs.

Three field findings from the first Obsidian evening closed the circle: an unconfigured vault now answers honestly (the Archive is never presented as the vault); a status question at the lab door shows the room instead of demanding code; and the vault gained its spoken handshake — tell Genesis where the vault lives, in any of the four locales, and he verifies the folder and stores the path himself, effective immediately, no JSON editing and no restart.

Housekeeping alongside: the documentation moved into its final shape. The two root heavyweights joined their kin — docs/CHANGELOG-v7.md beside its v5/v6 siblings, docs/AUDIT-BACKLOG.md beside the audit docs — with every link, the changelog splitter, and both gate scripts following the move (the language gate keeps the historical archive exempt by design, the drift gate loads the backlog from its new home). The root now holds exactly the seven files a visitor expects.
