## [7.9.35]

Eighteen idle activities produce — they reflect, plan, explore, dream, build. Not one of them lets Genesis deliberately do nothing. This release adds the nineteenth: **pause**, a legitimate choice of the IdleMind driven by the real rest need, and the first activity whose entire output is the choice itself. The trigger reads nothing but the raw rest level — the honest signal that already grows with metabolic depletion — scaling from neutral when rested to a threefold preference when exhausted; no invented time-of-day heuristics, no thresholds. The run makes no model call, uses no tools, fires no events and simulates no waiting: the idle tick is the time, and the metabolism's existing restore tick does the actual recovering. The choice costs one energy unit, the cheapest entry in the cost map by design.

What remains of a pause is one private journal line — "Ich habe geruht." with the current mood — written through the journal writer's native visibility routing via a new optional late-binding on the IdleMind, so a missing writer degrades to silence, never to failure. The short trace string feeds the standard activity pipeline, stays under the insight length floor, and pause is absent from the insight whitelist — proactive sharing is structurally excluded twice. The activity counts normally in the picker statistics, so the existing repetition penalty prevents pause loops for free, and the v7.9.12 rest-mode (the model-outage state, a condition that happens *to* Genesis) remains an explicitly different concept, untouched. One contract suite with seven pins covers registration as the nineteenth, the pure boost curve, the model-free run with its single private line, the double insight exclusion, the cost entry, and the naming-hygiene plus wiring source relations — 421 modules, 618 test files, services unchanged at 184.
